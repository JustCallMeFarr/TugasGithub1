# Tugas Pertemuan 6 JavaScript

Tugas ini terdiri dari dua file:

- `data.js` : berisi 10 data awal menggunakan Array of Object.
- `controller.js` : berisi proses melihat, menambah, dan menghapus data.

Fitur yang digunakan:
1. Menampilkan data menggunakan `map()`.
2. Menambahkan minimal 2 data menggunakan `push()`.
3. Menghapus data menggunakan `splice()`.

## Cara menjalankan

Pastikan Node.js sudah terpasang, kemudian buka terminal pada folder tugas dan jalankan:

```bash
node controller.js
```

Hasil proses akan tampil pada terminal.
